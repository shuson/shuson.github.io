TapXWorld 的 ChinaTextbook 是一个雄心勃勃的开源项目，旨在收集和开放中国从小学到大学的所有官方 PDF 教材资源。项目创建于 2020 年，汇集了人教版及各大出版社的电子教材，覆盖小学、初中（含五四学制）、高中以及大学高等数学、线性代数、离散数学和概率论等课程。项目的初衷直击痛点——尽管国内教育平台已提供免费资源，但大多数普通人的获取途径依然受限，部分人甚至在二手平台上兜售这些带有私人水印的资源牟利。作者希望通过开源集中化来打破信息壁垒，促进教育公平，同时也让海外华人子女能够继续接触国内教育体系。

从技术视角看，ChinaTextbook 本质上是一个基于 Git LFS（Large File Storage）的大文件仓库，仓库体积高达 43 GB，内含 138 次提交记录。项目采用 Roff 作为标注语言编写 README 等文档，但核心资产是数量庞大的 PDF 文件。由于 GitHub 对单文件上传有 100MB 上限（超过 50MB 会警告），项目中大于 50MB 的 PDF 均被拆分为每份 35MB 的多个分卷文件，并在 README 中提供了合并指引。这种"化整为零"的策略体现了开源社区应对平台限制的巧妙工程思维。目前项目已获得 77,925 ⭐ 和 17,648 次 Fork，是中文教育领域 Star 数最高的开源项目之一。

项目的目录结构按照学段清晰划分：小学（6个年级上下册）、小学五四学制、初中（3个年级上下册）、初中五四学制、高中以及大学数学。特别值得一提的是，仓库还包含了"学数学最重要的刷习题在这里/初中练习题_带答案"这一练习资源目录，从"看教材"延伸到"做练习"，形成了更完整的自学闭环。大学板块涵盖高等数学、线性代数、离散数学和概率论四大核心课程，并引用了大学数学网等外部资源链接。尽管项目存在版权灰色地带（教材版权归属原出版社），但其非商业化、纯公益的定位使其在教育社区中获得了广泛认可。

ChinaTextbook 此番再度登上 GitHub Trending 并非偶然。在全球华人家庭对中文教育资源需求持续增长的背景下，一个系统化、免费且持续维护的教材仓库具有不可替代的实用价值。它既是数字化时代教育资源共享的范本，也折射出开源运动超越代码范畴、向知识平权延伸的趋势。项目仓库托管在 TapXWorld/ChinaTextbook，欢迎 Star 和贡献。URL: https://github.com/TapXWorld/ChinaTextbook
