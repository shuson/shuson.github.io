GeoLibre is a free and open-source, lightweight cloud-native GIS platform built by the opengeos organization that brings professional-grade geospatial analysis to any device. It's designed to run everywhere — in the browser, as a native desktop app on Windows/macOS/Linux, on Android mobile, and even inside Jupyter notebooks — all while keeping data local and private. For anyone who's struggled with bloated, platform-locked GIS tools requiring complex installations, GeoLibre represents a breath of fresh air in the geospatial world.

Built with Tauri v2, React, TypeScript, MapLibre GL JS, DuckDB-WASM Spatial, and deck.gl, GeoLibre packs a serious technical punch. The same workspace seamlessly transitions from native desktop to mobile to browser without missing a beat. Its secret weapon is DuckDB-WASM Spatial, which enables performant in-browser SQL queries and spatial analysis on large datasets with zero server dependency. The architecture includes a Python backend (geolibre_server), Cloudflare Workers for edge computing, and Docker support for self-hosting. Stars: 4,021 ⭐ (+4,021 total since launch in May 2026).

The feature set is remarkably complete. It supports 3D Tiles with building extrusion and time-slider animations, planetary basemaps (from OpenPlanetaryMap and USGS Astrogeology) covering the Moon, Mars, Mercury, Venus, Pluto, and the Galilean moons — each with its own ellipsoid for accurate measurements. Over 700 geoprocessing tools run directly in the browser. There's a full SQL Workspace, attribute table editor, legend auto-generation, and responsive layouts for mobile. Integrations include Jupyter notebooks for Python users and Docker for server deployments.

GeoLibre is trending because it cracks a long-standing problem: making powerful GIS tools truly accessible and cross-platform without compromising on capability. The opengeos team has already shipped 918 commits and built a growing community with 430 forks and active discussions. As geospatial data becomes increasingly central to everything from climate science to urban planning, a tool that runs anywhere and keeps data local hits at exactly the right moment.
