Apache Maka (Incubating) is a new local-first AI agent workspace from the Apache Software Foundation, designed for real-world development work. Unlike cloud-dependent coding assistants, Maka operates entirely on your machine — model messages, tool calls, tool results, permission decisions, and termination events are all recorded as an append-only execution log. This means every interaction with the agent is transparent, recoverable, and stays under your control. Backed by the ASF incubation process, Maka represents a significant step toward open, auditable agent infrastructure.

Built in TypeScript with an Electron + React desktop shell and a monorepo architecture, Maka ships with 3,321 ⭐ stars and 329 forks. Its architecture centers on Runtime Host — a single local process that mediates all agent activity across every surface (desktop, CLI, and evaluation harness). The event-sourced design ensures that the complete agent execution record is preserved, and context truncation never destroys saved evidence. Users bring their own model — whether a cloud API, a local LLM, or a compatible gateway — and Maka handles the orchestration. With 3,865 commits from 289 branches, development velocity is intense.

Standout features include streaming sessions with tool timelines, conversation branching, full-text search across execution history, and one-click recovery. Built-in tools span Read, Write, Edit, Bash, Glob, and Grep, with experimental support for Computer Use and catalog skills. The TUI/CLI (`maka` and `maka run`) shares workspace and model connections with Desktop, while `maka eval` enables reproducible benchmark experiments. An early macOS Apple Silicon build is publicly available, signaling the project's commitment to shipping fast and iterating in the open.

Maka is trending because it tackles a growing anxiety in the AI coding space: what happens to your data and execution history when the agent runs? By making every decision auditable, keeping everything local-first, and placing the project under ASF governance, Apache Maka offers a compelling alternative to closed, cloud-only coding agents. For developers who care about transparency, ownership, and reproducibility, Maka is worth watching closely. URL: https://github.com/apache/maka
