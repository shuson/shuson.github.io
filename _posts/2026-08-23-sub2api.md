Sub2API is an open-source AI API gateway platform built by developer Wei-Shaw that transforms the fragmented landscape of AI subscription management into a unified, efficient relay service. Originally created to solve a practical problem — how to share and distribute Claude/Codex/Gemini API quotas among teams without each person paying full subscription fees — Sub2API has grown into a full-featured platform that proxies requests to multiple AI providers while handling authentication, billing, rate limiting, and load balancing under one roof. With 38.8k stars and over 8,000 forks, it has quickly become the go-to solution for developers and teams looking to pool AI subscription costs or self-host their own API relay infrastructure.

Built primarily in Go for its high-performance backend, with a Vue.js + TypeScript admin frontend, Sub2API delivers production-grade reliability at scale. The architecture features a multi-account management system that supports OAuth and API Key-based upstream accounts, token-level precision billing with usage tracking, intelligent sticky-session scheduling for consistent model responses, and per-user/per-account concurrency controls. Its smart rate limiting operates at both the request and token level, ensuring fair distribution of quota across shared accounts. The project ships with Docker deployment support, a comprehensive CLI toolchain, and goreleaser configurations for cross-platform binary distribution — making self-hosting accessible whether you're running on a VPS, a homelab, or Kubernetes. Stars: 38,781 ⭐.

Standout features include a built-in payment system supporting EasyPay, Alipay, WeChat Pay, and Stripe for user self-service top-ups — eliminating the need for a separate payment microservice. The admin dashboard provides real-time monitoring of usage, costs, and account health through a clean web interface. Composite Groups allow admins to resolve model requests across multiple upstream providers with intelligent routing, while the ecosystem has spawned community extensions like sub2api-mobile (a cross-platform Expo + React Native admin app for iOS/Android) and external integrations that embed ticketing and support systems via iframe. The platform supports Claude (Anthropic), OpenAI (including Codex), Gemini, Grok/xAI, and Antigravity models — and is compatible with virtually any OpenAI-format compatible API, making it a universal translation layer for the AI ecosystem.

Sub2API's meteoric rise reflects the growing demand for infrastructure that democratizes access to premium AI models. As coding agents like Claude Code and Codex CLI become essential developer tools, the need for cost-effective, self-hosted relay solutions has exploded — and Sub2API has positioned itself at the center of this movement. Its vibrant sponsor ecosystem (over a dozen relay service providers now sponsor it) and massive contributor base signal that the AI subscription relay space is maturing into its own distinct infrastructure category.
