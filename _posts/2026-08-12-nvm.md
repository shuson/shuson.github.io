Node Version Manager (nvm), maintained by the nvm-sh organization and led by longtime steward Jordan Harband (ljharb), is the gold standard for managing multiple Node.js versions on POSIX-compliant systems. Written entirely as a bash script, nvm lets developers install, switch between, and isolate any version of Node.js with a single command — from ancient 0.x releases to the latest LTS — without root permissions or system-level package managers. For over a decade, it's been the first thing most JavaScript developers install after a terminal emulator, and its resurgence on trending today underscores how foundational it remains to the modern web stack.

Technically, nvm is a ~4,000-line bash script (94,484 ⭐, 10.4k forks) that hooks into your shell's runtime via `.bashrc` or `.zshrc`. It downloads precompiled Node binaries from the official distribution mirrors, stores them in `~/.nvm/versions/node/`, and swaps the active version by manipulating `$PATH`. Key innovations include `.nvmrc` auto-switching — drop a file in your project root and `nvm use` automatically selects the right Node version — and deep shell integration with `zsh` and `bash` that calls `nvm use` automatically when entering a directory. The project recently added `CLAUDE.md` and `AGENTS.md` files, signaling readiness for AI-assisted development workflows.

Standout features include seamless LTS support, offline installation via tarball, migration of global npm packages between versions, and Docker-first CI/CD patterns. It works on macOS, Linux, and WSL, with community support for Windows via `nvm-windows`. The `.nvmrc` pattern is now an ecosystem standard adopted by CI platforms, deployment pipelines, and monorepo tooling like Volta and fnm. With 2,388 commits from hundreds of contributors and a mature governance model, nvm exemplifies the longevity of well-designed Unix tools.

Despite competition from newer Rust-based alternatives like fnm and Volta that promise faster shell startup, nvm's trending status — and its relentless march toward 100,000 stars — proves that simplicity, reliability, and POSIX purity still win. It is the rare tool that every JavaScript developer has used, intentionally or not, and its continued relevance is a testament to the power of doing one thing exceptionally well.
