The AI coding agent landscape has a new heavyweight: **free-claude-code (FCC)** by Alishahryar1 lets you run Claude Code, OpenAI Codex, Pi, OpenCode, and five other coding agents entirely for free. With 1.3 billion+ free tokens available every month across 50 ToS-friendly providers, FCC has become the go-to bridge for developers who want top-tier AI coding assistance without the paywall. The project has skyrocketed to nearly 49,000 GitHub stars as developers flock to a unified gateway that preserves full agent capabilities—streaming responses, native interleaved thinking, tool use, and image input—without putting their provider accounts at risk.

Built primarily in Python (4.4M+ lines) with supplemental PowerShell, Shell, JavaScript, and TypeScript, FCC acts as a model-agnostic proxy layer between coding agent CLIs and dozens of LLM providers. The architecture is deliberately modular: a model catalog allows per-agent routing (Fable, Opus, Sonnet, and Haiku can map to different free/paid/local models independently), an automatic failover system keeps you coding through provider outages by switching to the next configured model mid-turn, and an optional RTK (Runtime Token Kit) module strips up to 90% of terminal-output tokens by filtering common command output, quota probes, and redundant metadata—all without calling a provider. Stars: 48,948 ⭐.

FCC's feature set is remarkably comprehensive. **Nine coding agents** are supported from one interface—Claude Code, Codex, Pi, OpenCode, Cline, Hermes Agent, DeepSeek Harness, Grok Build, and Muse Code. **Every platform matters**: native terminal launchers on macOS, Linux, and Windows; IDE integration via VS Code and JetBrains; desktop apps through Codex App; and even mobile/chat access through Discord and Telegram. **Voice is treated as a first-class input**: talk to your agent using local Whisper or NVIDIA NIM transcription and get code back. A searchable provider UI lets you browse and select from free, paid, subscription, and local models. One-liner install scripts make onboarding trivial: `curl -fsSL "https://raw.githubusercontent.com/Alishahryar1/free-claude-code/main/scripts/install.sh" | sh`.

FCC's meteoric rise reflects a broader shift in developer tooling: the appetite for AI-assisted coding is enormous, but so is the frustration with per-seat pricing and token caps. By aggregating free provider tiers—without violating ToS—FCC democratizes access to frontier coding agents. It's an independent, MIT-licensed project unaffiliated with Anthropic, and it removes providers if they stop being allowed. As the agent ecosystem fragments across Claude Code, Codex, and a dozen other shells, a single launcher that abstracts away the model plumbing while preserving each agent's full feature set is exactly what developers have been waiting for.
