Cordis is a TypeScript meta-framework built by the Cordiverse organization that introduces a novel programming paradigm called "spatiotemporal composability." It serves as the plugin backbone for DeepSeek Harness — DeepSeek's enterprise-grade AI agent infrastructure — handling everything from LLM adapter injection to tool schema registration, conversation node orchestration, and persistent event streams. Rather than being yet another agent framework, Cordis provides the architectural substrate on which agent frameworks are built: a dependency-injected, event-driven plugin system where every component declares its required services and the runtime resolves startup ordering automatically.

Built entirely in TypeScript (~242K LOC), Cordis is organized as a monorepo with a clean ESLint/Vitest toolchain. Its core innovation is a four-mode event dispatch system — `emit` (fire-and-forget observation), `waterfall` (wrapping middleware with downstream delegation), `parallel` (concurrent fan-out with await), and `serial` (sequential execution with return values). Services occupy stable `Context` keys, and plugins declare dependencies that the loader resolves before activation. This eliminates manual startup sequencing: Cordis derives the correct initialization order from the dependency graph itself. With 4,059 ⭐ (+hundreds today) and 198 forks, the framework has gained traction for its elegant separation of concerns and its proven deployment at scale behind DeepSeek's production agent systems.

Standout capabilities include pluggable LLM adapters allowing Drop-in model provider swapping without code changes, tool schemas registered via `ctx.effect()` with automatic teardown on reload, a Fiber-based reactive context system for scoped plugin lifecycles, and a comprehensive event taxonomy that supports waterfall middleware for prompt transformation and serial dispatch for ordered execution pipelines. The framework also integrates deeply with the DeepSeek ecosystem — its documentation hub covers subsystems for kernels, sessions, persistence, model context, tool execution, strategy/interaction, and platform access, making it a complete operating system for AI agent development.

Cordis is trending because it represents a shift in how the open-source community thinks about AI agent infrastructure. Instead of monolithic agent SDKs that hard-code provider integrations and execution flows, Cordis offers a composable, dependency-driven architecture where agents are assembled from interchangeable plugins. Backed by the DeepSeek team and battle-tested in production, it's attracting attention from developers building next-generation agent systems who want the same level of architectural rigor that Cordis brings to the table.
