Needle 2, from cactus-compute, is a staggering feat of compression: a 45-million-parameter foundation model for tool calling and structured extraction that fits into a single 14MB binary and runs inside just 28MB of RAM. In an era where frontier models measure their footprints in hundreds of gigabytes, Needle 2 is a deliberate reversal — a model purpose-built for phones, wearables, smart home hubs, and embedded robots, proving that on-device intelligence doesn't need a data center behind it.

Built in Python and released under the MIT License, Needle 2 is grounded in Cactus Compute's Simple Attention Network research and compressed to CQ2-bit precision using their own Cactus Quants technique. The entire inference engine — weights and all — ships as one self-contained binary fetched once from Hugging Face and cached locally. There is nothing to build, and no network calls during inference. On industry benchmarks it trades wins with models 5× to 70× larger — including FunctionGemma 270M, LFM2.5 230M, and Apple's Foundation Model — while running at just 2 bits against their float16. Stars: 5,593 ⭐ (+ massive gains today).

The architecture is aggressively minimalist by design. It uses a 256-token sliding window with tools pinned as KV sinks to keep total memory bounded near 28MB. A byte-level grammar compiled from user-defined JSON schemas constrains every output token, guaranteeing structured, schema-compliant tool calls every time. Every response carries a calibrated confidence score from a learned head, enabling a clean threshold-based action-or-escalate pattern. For large tool catalogs, a built-in retrieval head renders only the top five relevant tools per turn, with the grammar constrained to that subset. Installation is a single `pip install cactus-needle`, and offline air-gapped setup is fully documented.

Needle 2 is trending because it rewrites the on-device AI playbook at a moment when the industry is searching for viable edge deployment strategies. At 14MB it can live on hardware that most engineers wouldn't even consider AI-capable — and it comes with LoRA fine-tuning and model export support, so developers can adapt it to domain-specific tool schemas. For anyone building ambient computing, offline assistants, or autonomous embedded agents, this is the kind of performant, license-permissive foundation that makes those products possible today rather than someday.
