What if you could sit at a spy-satellite console in your browser and pan across a live, photorealistic 3D Earth — except every aircraft, ship, earthquake, and satellite on screen is fed by real public telemetry? That's **God's Eye View**, the newly open-sourced spatial intelligence platform by Bilawal Sidhu. Built as the engine behind the viral "WorldView" YouTube series (5M+ views), this project transforms scattered OSINT browser tabs into a single, immersive geospatial cockpit. Open sourced just three days ago, it has already racked up nearly 8,000 stars as developers rush to explore — and extend — a tool that looks like classified military software but runs entirely on public signals.

At its core, God's Eye View is a JavaScript application built on CesiumJS and WebGL, rendering a 3D globe in the browser that streams live data from public APIs and open feeds. Flight transponders (ADS-B), ship AIS beacons, orbital satellite elements, earthquake seismographs, traffic cameras, and public webcam streams are all fused into a single map interface. The client deliberately buffers flights one polling interval behind real time to produce smooth interpolated movement rather than jittery raw telemetry. The codebase — 8.3M lines of JavaScript, plus CSS, HTML, and Shell tooling — is organized into a modular structure: `config/` for API keys and data sources, `src/` for the core rendering and logic, `scripts/` for data ingestion pipelines, and `tools/` for utilities. Stars: 7,976 ⭐ (trending #1 daily).

The feature set reads like a Hollywood intelligence terminal made real. You can ride inside a tracked flight in cockpit view with terrain-locked perspective; target anything on the globe with a click to lock the camera and surface full metadata; stand up a 250 km "contacts roster" of everything around a point of interest; and even speak voice-annotated boundary polygons and routes onto the world. Real per-class 3D aircraft models (787, ATR-72, Citation, Bell 206, MQ-9) replace generic glyphs as you zoom in. A GLSL shader system lets you reskin reality with CRT, night-vision, FLIR thermal, noir, and snow sensor looks — plus a tactical military HUD mode with screen-space bounding boxes and detection overlays. Every layer is transparency-labeled: live, modeled, partial, delayed, simulated, or unavailable.

God's Eye View matters because it represents a turning point in open-source geospatial intelligence. The signals have always been public — ADSB Exchange, OpenSky Network, AIS vessel tracking, USGS earthquake feeds, and public traffic cameras — but until now, no one had stitched them into a coherent, real-time 3D experience that anyone with a browser could run locally. The project's explosive debut on GitHub trending confirms an appetite for democratized spatial awareness tools that don't require a defense budget. As the README puts it: "the world is already broadcasting — and the interface runs in your browser, under your control." URL: https://github.com/bilawalsidhu/gods-eye-view
