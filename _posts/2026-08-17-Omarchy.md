Omarchy is a beautiful, modern, and opinionated Linux distribution created by David Heinemeier Hansson (DHH) — the creator of Ruby on Rails and co-founder of Basecamp/37signals. Born from DHH's frustration with existing Linux desktop experiences, Omarchy takes the "omakase" philosophy (chef's choice, famously applied to Rails) and applies it to the entire operating system. Built on Arch Linux, it delivers a meticulously curated desktop where every aesthetic, keyboard shortcut, and application choice has been made for you — no endless tinkering required.

Built primarily in Shell, QML, JavaScript, Python, and Lua, Omarchy is an Arch-based distribution that ships with a custom desktop environment centered around speed and beauty. The project has exploded in popularity, amassing 25,367 ⭐ on GitHub, with active development across 59 branches and 6,093 commits. The latest milestone, "Omarchy Quattro," was recently released and represents the fourth major iteration of the project, complete with a custom theming engine that supports community-created visual styles.

Omarchy stands out with its opinionated curation of the Linux desktop. It includes a unified clipboard and history system, built-in reminders and notices, text extraction and dictation capabilities, screenshot and screen recording tools, and an Omarchy CLI for system management. The environment ships with Terminal (Kitty), Neovim as the default editor, integrated AI development tools, and a hand-picked set of TUI and GUI applications. The theming system is particularly notable — users can choose from dozens of community themes or create their own, with hotkeys and window management tuned for keyboard-first workflows.

Omarchy represents a compelling vision: that Linux on the desktop can be beautiful without requiring users to spend hours configuring every pixel. By applying the same "convention over configuration" philosophy that made Rails revolutionary, DHH is attempting to do for the Linux desktop what Rails did for web development — make it delightful, productive, and opinionated enough that you can stop tweaking and start building. Whether you're a developer seeking a polished environment or a Linux newcomer looking for a guided experience, Omarchy is worth a look. URL: https://github.com/basecamp/omarchy
